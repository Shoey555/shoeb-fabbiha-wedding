# Shoeb & Fabbiha — Integrated Wedding Invitation

A single, mobile-first opening page with a portrait background video blending directly into the wedding names, family details, countdown, Quranic excerpt and **one** Enter Invitation button at the very bottom.

## Update GitHub Pages

1. Download and extract the ZIP file.
2. Open `https://github.com/shoey555/shoeb-fabbiha-wedding`.
3. Select **Add file → Upload files**.
4. Upload **all six extracted files** directly to the repository root (do not upload the ZIP or an enclosing folder).
5. Select **Commit directly to the main branch** and press **Commit changes**.
6. Once deployed, preview `https://shoey555.github.io/shoeb-fabbiha-wedding/?v=7` on an iPhone.

The responsive site uses `intro-mobile.mp4` on phones and `intro.mp4` on larger screens. The MP4 files are hosted by your GitHub Pages site, not YouTube. Video is muted and plays inline where permitted by the browser. Poster images provide a fallback.

Countdown: 31 March 2027 at 17:00 British Summer Time (UTC+1). Enter Invitation leads to `https://withjoy.com/shoeb-and-fabbiha-mar-2027`.
