# Shoeb & Fabbiha — wedding intro page

This is a mobile-first opening page that embeds the YouTube intro and links guests to the Joy wedding website.

## Publish with GitHub Pages

1. Sign in to GitHub and create a new **public** repository, for example `shoeb-fabbiha-wedding`.
2. Upload `index.html` to the repository root (the top level, not inside another folder).
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. Wait for GitHub Pages to publish. The public URL will appear in Settings → Pages.

The intro video is embedded from YouTube and starts muted where browser autoplay allows. Guests can use the player controls if they want to play it manually. The Enter Invitation link opens the Joy website.

Before sharing, test the published link on an iPhone and Android phone. Confirm the YouTube video is set to **Unlisted** (not Private). You can change the names, date, video ID, and Joy destination in `index.html`.
